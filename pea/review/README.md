# Review boundary

Plans and analytical results begin `unreviewed`. Inspect the request, explicit
technical assessment, rejected paths, tool/platform availability, source evidence
and model limitations before adopting a proposal. Integration tests in Registry
metadata do not prove physical fidelity or a measured design.

The initial adapter appends analytical evidence and a namespaced extension. It
does not change selected devices, magnetics, control, simulation runs, thermal
results or the state's physical validation status. An existing extension/result
must be deliberately revised rather than silently overwritten. No automatic
merge, solver execution, software installation or model download occurs.

Changing an evidence item to reviewed is an engineering action, separate from
metadata validation. Preserve rejected/superseded evidence and explain the new
revision. Check full Core semantic validation as well as this consumer's schema
checks before publishing states across repositories.
